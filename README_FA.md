# Music Danial Manager 🎵

ربات مدیریت کانال موزیک تلگرام.

## امکانات
- انتشار موزیک/فایل صوتی در کانال
- ساخت کپشن استاندارد
- زمان‌بندی پست
- صف انتشار
- پین کردن پست
- حذف پست با شناسه
- تغییر توضیحات کانال
- ثبت لاگ عملیات در SQLite
- محدود کردن دستورات به ادمین‌های مجاز

## نکته امنیتی
توکن BotFather را داخل کد ننویس و برای کسی ارسال نکن. آن را فقط در فایل `.env` روی سرور قرار بده.

## نصب
1. Python 3.11+ نصب کن.
2. `pip install -r requirements.txt`
3. `.env.example` را به `.env` تبدیل کن.
4. BOT_TOKEN و ADMIN_USER_ID را وارد کن.
5. ربات را در کانال ادمین کن و دسترسی Post Messages و Edit Messages بده.
6. `python bot.py`

کانال نمونه این پروژه: `@musicdanial2023`

این پروژه برای مدیریت محتوایی است که حق انتشار آن را داری؛ از آن برای بازنشر غیرمجاز آثار دارای کپی‌رایت استفاده نکن.
